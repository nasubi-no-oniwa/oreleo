# オ？レ？レ？オ？

オ（チョコ）とレ（クリーム）を、シーソーで飛ばして皿に積むゲーム。崩れたら、積んだ順に下から全部読み上げられる。

- オかレをえらぶ（レはオの1.5倍の厚さで、すこしすべる）
- 長押しで重りを上げて、はなすと重りが落ちてシーソーで飛ぶ（上げすぎると飛びすぎる）
- 皿から落ちたら1こにつき1アウト。3アウト（または「おわる」）で終わり
- 最後に、残ったものを下から全部読み上げる（声は4種類＋端末の声）
- 読み上げ動画をつくって、そのままXに上げられる
- 積んだ数のランキング（並びも残る）

あそぶ: https://nasubi-no-oniwa.github.io/oreleo/

なすびのお庭: https://nasubi-no-oniwa.github.io/

## ランキングの置き場所
フェアリーズタワーの Firebase（緑の同盟 `ft-green`）の `oreleo/` に入る。
ルールは `rules/ft-green_rules.json`（フェアリーズタワーの分＋このゲームの分）を、ft-green の Realtime Database の「ルール」にまるごと貼って「公開」する。

## 動画の声
`voice.js` の「オ」「レ」の声は、Open JTalk（pyopenjtalk）で作ったもの。
